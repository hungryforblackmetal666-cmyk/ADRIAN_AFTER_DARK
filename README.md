# ADRIAN: AFTER DARK — Sandbox Edition

Ren'Py Android game prototype. The current v1.0 source package is a playable-source prototype, not a finished or tested APK.

## Source package
Upload `ADRIAN_AFTER_DARK_v1_0_Playable_Source.zip` from the ChatGPT conversation to this repository's root. Keep the archive filename unchanged. The archive contains the Ren'Py project folder.

## Android build status
No APK has been built yet. Android packaging and CI configuration will be added after the source archive is present and the Ren'Py Android toolchain is verified.

## Prototype contents
- Prologue and Chapter 1
- Four locations and menu-driven sandbox hub
- Time, energy, money, reputation and suspicion systems
- Relationship scores, messages, inventory and clues
- Fifteen-character roster

Art, audio, final renders, and a full production build are not included.
